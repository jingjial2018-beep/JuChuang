# JNest v1.0.5-beta.5

- Tray right-click: compact three-item WPF menu matching JNest built-in visual style, with cursor-relative screen-edge-aware placement: 显示主窗口 / 开机自启 / 退出.
- Left click restores the app; startup checkbox tracks actual startup state; Exit invokes existing confirmation.
- Taskbar: enlarged ICO is now the app's EXE/Window icon, rather than only a large HWND icon override; original app.ico remains available for tray and titlebar small icon. Intended 12% enlargement.
- All beta.4 dialog and hide-to-tray behavior retained.

Unsigned prerelease; verify appearance on Windows 11, especially pinned taskbar icon cache, monitor scaling and right-click placement.
