# JNest v1.0.5-beta.4

- Titlebar close (X) hides JNest into the existing system tray without exiting or prompting.
- Tray left click restores the main window; regular minimize keeps the Windows taskbar entry.
- Exit JNest menu and tray Exit retain the existing explicit exit-choice dialog.
- Hosted WeChat/WhatsApp windows are parked while JNest is hidden, then reactivated on restore.
- Client exit description block: 300 DIP; JNest exit-choice description block: 320 DIP. Font sizes, dialogue size and existing buttons unchanged.
- Includes all v1.0.5-beta.3 taskbar and menu icon improvements.

This is an unsigned Windows x64 prerelease. Native hosted window state transitions need real-device UI validation.
