# JNest v1.0.5-beta.6
- Tray right-click popup now opens adjacent to the click position rather than centered far to the left, with 6 DIP gap and active-screen edge adjustment, including top taskbars.
- Startup toggle displays a right-side checkmark when enabled; opening the popup refreshes its state from Windows.
- All beta.5 tray styles, menu items, taskbar assets and application behaviors retained.
- UI positioning on Windows 11 overflow tray requires user visual acceptance.
