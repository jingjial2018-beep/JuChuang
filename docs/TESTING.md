# JNest 测试包验收说明

本清单用于新生成的测试包，不代表相关项目已经通过。测试前记录包名、提交 SHA、Windows 版本、客户端版本和显示缩放比例。

当前正式版源码请检出对应 tag；默认分支 main 尚未同步 v1.0.7。PR 测试包基于该 PR 的源码，不能仅凭 README 将其视为正式版。

## 自动验证

- WPF Release 构建通过。
- ArchitectureProbe 和 BadgeProbe 通过。
- FrameworkDependent 和 SelfContained 两种包均可生成；包内含本说明、许可证和第三方声明。

## Windows 实机验收

- 启动 JNest，检查主窗口、任务栏和托盘图标；最小化、托盘隐藏与恢复正常。
- 打开多个微信窗口和 WhatsApp，检查扫描、接入、账号切换、弹出和重新接入。
- 微信关闭到托盘后重新接入，直接单击客户端工作区，检查输入是否响应。
- 打开设置、关于或退出确认框，切换到其他程序再返回，检查弹窗可见、背景客户端不可被误操作。
- 检查新消息角标、免打扰、提示音和通知；不得把历史未读误判为新消息。
- 检查常用缩放比例和多显示器切换，确认文字、按钮和窗口边界正常。
- 若测试提交含密码锁：验证锁定、错密码、正确解锁、锁定后退出重启及锁屏遮挡；密码锁验收不适用于尚未含该功能的旧 main。

每项记录“通过 / 失败 / 不适用”和复现步骤。自动检查通过不能替代真实客户端的鼠标、焦点和显示缩放验收。
