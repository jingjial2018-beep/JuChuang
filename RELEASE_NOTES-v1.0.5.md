# JNest v1.0.5 (stable)

This release integrates the accepted v1.0.5 beta improvements and final adjustments:

- Settings window: 540×520 DIP, vertically scrollable settings section with fixed bottom status and Close button, preventing bottom content truncation.
- Tray menu: suppress repeated right-click activation near the original tray icon while already open; preserve outside left/right dismissal and other tray icon operations.
- Maintains JNest tray-menu design, hide-to-tray, startup checkmark, dedicated taskbar icon and earlier dialogs.
- Unchanged client process exit, WeChat/WhatsApp hosted windows and notifications.

Windows win-x64 builds are unsigned. The native system tray interaction requires hands-on validation on the user's top-positioned Windows taskbar and overflow flyout.
